# scoopgrid

Scoop lightweight grid statistics from stdin samples.

**Site:** https://theworker02.github.io/scoopgrid/

## Install / run

```bash
git clone https://github.com/theworker02/scoopgrid.git
cd scoopgrid
node src/cli.js
node --test
```
